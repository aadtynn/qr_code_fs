# QR Code Generator & Decoder

A full-stack application for generating and decoding QR codes, built as a learning project to demonstrate full-stack development skills.

## 🚀 Features

### Phase 1: CLI Tool ✅
- Generate QR codes from text input
- Decode QR codes from image files
- Save QR codes as PNG files

### Phase 2: Web Application (In Progress)
- Django/Flask REST API backend
- React frontend with modern UI
- User authentication
- QR code history and management

## 🛠️ Tech Stack

- **Backend:** Python, Django (Flask coming soon)
- **Frontend:** React (coming soon)
- **Libraries:** qrcode, pyzbar, Pillow

## 📦 Installation
```bash
# Clone repository
git clone https://github.com/aadtynn/qr-code-fullstack.git
cd qr-code-fullstack

# Install dependencies
pip install qrcode[pil] pyzbar pillow

# Run CLI tool
python qr_tool.py
```
